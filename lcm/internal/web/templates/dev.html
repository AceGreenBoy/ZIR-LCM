Розробка

Збірки для розробки (CONFIG_ZIR_DEV_BUILD=y, PlatformIO esp32dev) сервер не підписує, лише шифрує ключем K_ota конкретного приладу. Отримують їх тільки прилади розробника. Такий прилад перевіряє оновлення кожні 30 с.

.pio/build/esp32dev/firmware.bin. Сервер перевірить zir_custom_desc_t: ознака dev-збірки обов'язкова, профіль має існувати.

Інтерфейс:

www.tar веб-інтерфейсу (npm run pack), без підпису. З образом — прилад поставить його разом зі збіркою. Без образу — лише інтерфейс: він ставиться поверх збірки розробника, що вже на приладі, без перезавантаження. www_api у manifest.json має збігатися з прошивкою.
