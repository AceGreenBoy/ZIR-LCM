Прошивка

Непідписаний firmware.bin, зібраний з sdkconfig.release.defaults і профілем. Сервер прочитає профіль і версію з zir_custom_desc_t, відхилить збірку для розробки й підпише образ.

Веб-інтерфейс

www.tar з npm run build && npm run pack. Усередині має бути нестиснутий manifest.json з version і www_api.

Bootstrap

Один образ з адреси 0x0: bootstrap/.pio/build/bootstrap/zir3m-bootstrap-<версія>.bin. Сервер перевірить розмітку, версію і що образ зібрано для цього сервера (його ключі). Прошивається зі сторінки «Прошивка USB».
